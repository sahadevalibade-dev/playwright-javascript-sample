# Playwright JavaScript Sample Project

This is a clean, minimal Playwright example configured with JavaScript for learning automation in Visual Studio Code.

## Getting Started

1. **Extract the ZIP file** into your preferred workspace directory.
2. Open the folder in **Visual Studio Code**.
3. Open the VS Code Terminal (`Ctrl + ~`) and run:
   ```bash
   npm install
   npx playwright install
   ```

## Running the Sample Tests

* **Run all tests in headless mode:**
  ```bash
  npm run test
  ```
* **Run tests in interactive UI Mode (Highly Recommended for learning):**
  ```bash
  npm run test:ui
  ```
* **View the HTML execution report:**
  ```bash
  npm run test:report
  ```
